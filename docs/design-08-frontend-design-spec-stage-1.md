# MindOra 前端设计规格：Stage 1

## 1. 文档目的

本文档用于定义 MindOra 在 Stage 1 的前端界面设计范围与页面规格，作为设计、前端实现和后续迭代的共同依据。

本文档仅包含以下内容：

- 设计清单
- 页面目标
- 主要模块
- 关键交互

本文档不限制具体视觉风格、动效实现方式或前端技术细节。

后续阶段继续沿用本类文档维护，建议按阶段新增对应文档，例如：

- `design-09-frontend-design-spec-stage-2.md`
- `design-10-frontend-design-spec-stage-3.md`

## 2. Stage 1 设计范围

Stage 1 的前端设计范围分为两部分：

- 公共站点
- 管理后台

Stage 1 需要覆盖的页面如下：

1. 公共站点首页
2. 公共文章列表页
3. 公共文章详情页
4. 管理后台登录页
5. 管理后台文章列表页
6. 管理后台文章编辑页
7. 管理后台分类与标签页

## 3. 设计清单

### 3.1 公共站点

#### 页面 1：首页

**页面目标**

- 建立 MindOra 的品牌感和内容气质
- 让用户快速理解站点是做什么的
- 展示最新已发布文章
- 提供进入文章列表页的明确入口

**主要模块**

- 顶部导航
- 首页首屏信息区
- 最新文章区
- 分类或主题入口区
- 页脚信息区

**关键交互**

- 点击品牌返回首页
- 点击导航进入文章列表页
- 点击首页文章卡片进入文章详情页
- 点击“查看全部文章”进入文章列表页
- 点击分类或主题入口进入已筛选的文章列表

#### 页面 2：文章列表页

**页面目标**

- 展示全部已发布文章
- 支持按照分类和标签筛选内容
- 让用户能够快速扫描并进入感兴趣的文章

**主要模块**

- 页面标题区
- 分类筛选区
- 标签筛选区
- 文章列表区
- 空状态提示区

**关键交互**

- 切换分类筛选文章
- 切换标签筛选文章
- 清空筛选条件
- 点击文章卡片进入文章详情页
- 当无结果时展示空状态提示

#### 页面 3：文章详情页

**页面目标**

- 提供稳定、清晰的阅读体验
- 展示文章标题、摘要、发布时间、正文等核心信息
- 提供返回文章列表的路径

**主要模块**

- 返回入口
- 文章标题区
- 文章元信息区
- 摘要区
- Markdown 正文区

**关键交互**

- 返回文章列表页
- 通过浏览器前进后退保持阅读路径
- 正文中的常规链接可正常跳转

### 3.2 管理后台

#### 页面 4：后台登录页

**页面目标**

- 提供管理员登录入口
- 明确展示登录失败信息
- 作为管理后台的唯一访问起点

**主要模块**

- 品牌标识区
- 登录表单区
- 错误提示区

**关键交互**

- 输入邮箱和密码后提交登录
- 登录失败时展示明确错误提示
- 登录成功后进入后台文章列表页

#### 页面 5：后台文章列表页

**页面目标**

- 查看当前全部文章
- 按状态筛选文章
- 执行新建、发布、下线等核心操作
- 明确区分哪些文章可以编辑

**主要模块**

- 页面标题与主操作区
- 状态筛选区
- 文章表格或列表区
- 操作按钮区
- 全局提示区

**关键交互**

- 点击“新建文章”进入文章编辑页
- 按状态筛选文章
- 对草稿和已下线文章进入编辑
- 对已发布文章执行下线
- 对草稿或已下线文章执行发布
- 操作成功或失败后展示明确提示

#### 页面 6：后台文章编辑页

**页面目标**

- 支持创建新文章
- 支持编辑草稿和已下线文章
- 支持维护文章基础信息、正文、封面、分类、标签和可见性

**主要模块**

- 页面标题区
- 基础信息表单区
- 分类与标签选择区
- 封面上传区
- Markdown 编辑区
- 页面操作区
- 成功或错误提示区

**关键交互**

- 输入标题、slug、摘要和正文
- 选择分类
- 勾选标签
- 切换可见性
- 上传封面图片
- 移除已关联封面
- 保存草稿
- 取消编辑并返回文章列表页
- 当保存失败时展示明确错误提示

#### 页面 7：后台分类与标签页

**页面目标**

- 维护文章可用的分类和标签
- 支持快速新增基础分类与标签
- 为文章编辑提供可复用的内容组织结构

**主要模块**

- 页面标题区
- 分类管理区
- 标签管理区
- 当前分类列表区
- 当前标签列表区
- 错误提示区

**关键交互**

- 输入分类名称并新增分类
- 输入标签名称并新增标签
- 新增失败时展示明确错误提示
- 新增成功后即时刷新当前列表

## 4. Stage 1 页面关系

Stage 1 页面关系如下：

1. 首页进入文章列表页或文章详情页
2. 文章列表页进入文章详情页
3. 文章详情页返回文章列表页
4. 后台登录页进入后台文章列表页
5. 后台文章列表页进入文章编辑页
6. 后台文章列表页进入分类与标签页
7. 文章编辑页返回文章列表页

## 5. Stage 1 设计完成标准

当以下条件满足时，可认为 Stage 1 前端设计规格完整：

- 公共站点首页、列表页、详情页的页面边界清晰
- 管理后台登录、文章列表、文章编辑、分类与标签页的页面边界清晰
- 每个页面都有明确的页面目标
- 每个页面都有明确的主要模块
- 每个页面都有明确的关键交互
- 页面之间的跳转关系明确

## 6. 后续维护方式

后续阶段继续按相同结构维护前端设计规格文档。建议保持以下约定：

- 每个阶段一份独立文档
- 统一使用中文
- 每份文档至少包含设计清单、页面目标、主要模块、关键交互
- 新阶段增加页面时，优先补齐页面职责和交互边界，再进入视觉设计或实现
