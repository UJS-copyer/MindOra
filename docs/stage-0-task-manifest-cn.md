# Stage 0 阶段文档：工程底座（Engineering Foundation）

> 一句话用途：记录 Stage 0 工程底座的 Spec 设计目标与实现交付情况。  
> 维护日期：2026-10-17　状态：**已完成**

---

## 1. Spec 设计目标

本阶段旨在为整个个人知识库与问答系统搭建一个稳定、干净、易于本地运行的工程底座，确立规范的分层边界与基础服务：

1. **后端模块化单体架构**：采用 Spring Boot 3 与 Java 21，按业务清晰划分子模块，各模块只通过稳定的接口向外暴露能力，杜绝模块间代码混乱调用。
2. **前端工程规范**：采用 Vue 3 + Vite 的 Monorepo 结构，配置 TypeScript 类型检查与代码风格规范。
3. **基础设施环境容器化**：MySQL、Redis、向量数据库 Qdrant、RocketMQ 等基础中间件统一运行在 Ubuntu 虚拟机中的 Docker Compose 容器里，不侵入开发机本体环境。
4. **统一基础服务规范**：建立全局统一的 API 返回格式（包含状态码、提示信息、追踪 ID）、统一异常处理拦截器以及基于 JWT 的用户登录与权限鉴权机制。

---

## 2. 实现情况

本阶段所有核心目标已全部达成，代码和配置已稳定入库：

1. **后端基础骨架落地**：创建并规范了 10 个业务与支撑模块（`mindora-common`、`user`、`blog`、`knowledge`、`asset`、`rag`、`admin`、`task`、`adapter`、`app`），模块职责明确。
2. **虚拟机基础设施就绪**：虚拟机 Docker 服务稳定运行，数据库、缓存与向量库端口可直连访问，支持数据卷持久化。
3. **安全与通用契约跑通**：用户注册登录、JWT 签发校验、统一返回包装器与全局异常处理器全部通过单元测试。
4. **测试与构建基线**：全套后端服务测试与前端类型检查命令全部畅通，为后续内容与知识库功能的开发提供了可靠的底座支持。
