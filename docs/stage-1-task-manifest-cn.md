# Stage 1 阶段文档：内容与后台管理（Content and Admin）

> 一句话用途：记录 Stage 1 博客内容管理与展示链路的 Spec 设计目标与实现交付情况。  
> 维护日期：2026-10-17　状态：**已完成**

---

## 1. Spec 设计目标

本阶段旨在打通从「后台撰写编辑」到「前台公开发布阅读」的最小可用内容闭环：

1. **内容管理生命周期**：支持文章的撰写、草稿保存、正式发布与下线撤回；支持给文章归类、打标签以及设置封面图。
2. **Markdown 沉浸式编辑**：选型 Markdown 编辑器（`md-editor-v3`），支持左右分栏实时预览、复制粘贴图片自动上传至素材库，正文内容与渲染展现解耦。
3. **静态图片与素材管理**：提供统一的素材上传与管理能力，为文章插图和封面提供稳定的存储支持。
4. **前台博客浏览**：提供简洁的前台网站，包含首页导航、文章列表展示、分类与标签多维度筛选、正文阅读以及阅读计数。

---

## 2. 实现情况

本阶段核心功能已全部交付，前后端链路通畅：

1. **后台管理端落地**：后台界面采用 Art Design Pro 方案（`apps/admin-art`），完成了登录、文章列表与编辑、分类标签维护、图片素材管理、用户管理等核心管理页面。
2. **前台展示站点就绪**：前台站（`apps/site`）实现了响应式首页、文章分页列表、分类标签联动过滤与 Markdown 文章排版渲染。
3. **数据库表结构沉淀**：通过 Flyway 迁移脚本（V1~V5）在 MySQL 中固化了用户、角色、文章、分类、标签等基础业务表，支持自动化数据版本迭代。
4. **编辑与发布闭环**：实测后台可流畅编辑 Markdown 文章，插入本地图片并即时发布；前台网站可实时浏览发布的新文章，阅读量自动累加。
