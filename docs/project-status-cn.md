## 3. 开发环境关键约束与已知问题

1. **Lucene 嵌入式单写者锁（重要）**：
   - 关键词检索采用进程内嵌入的 Lucene 引擎，索引保存在本地磁盘。
   - **本地不能同时启动两个后端进程**。如果重启后端时旧进程未完全退出，新进程会因为无法获取 `write.lock` 锁而启动失败。遇到此类报错时，请先确保彻底杀掉旧的 Java 进程。
2. **虚拟机网络与 Docker 端口直连**：
   - Docker 容器运行在 Ubuntu 虚拟机中（`192.168.222.128`），宿主机可直接连接 MySQL、Redis 与 Qdrant。
   - 若偶发宿主机直连虚拟机超时，可按 `docs/development-startup-cn.md` 建立 SSH 端口转发隧道（`13306 -> 3306`、`16333 -> 6333`、`16379 -> 6379`）并在本地配置中覆盖端口。
3. **VM Docker 网桥注意点**：
   - 运行中若偶发出现“连接 MySQL 超时，但虚拟机中 docker 容器仍在运行”的现象，多为虚拟机 Docker 网桥临时丢失 IPv4 地址导致。
   - 解决方案：在虚拟机中执行 `ip addr add 172.19.0.1/16 dev br-ff83ebfa1109` 即可瞬间恢复，无需重启容器。
4. **服务启动隔离**：
   - 本地运行日志统一输出至仓库根目录下的 `logs/` 目录。
   - 后端服务、前台站点、后台管理前端三个常驻进程应在各自独立的终端窗口中启动，请勿拼在同一条复合命令中运行。
5. **前端请求同源（2026-10-18 约定）**：
   - 两个前端一律用**相对路径** `/api`，由各自 `vite.config.ts` 的 `/api` 规则代理到 `http://localhost:8080`；
   - **不要**把 `VITE_API_BASE_URL` 配成绝对后端地址——那会让浏览器按跨源处理，登录态 Cookie 变成第三方 Cookie；
   - 生产同域：Nginx 托管静态文件并反代 `/api`，因此不需要 CORS、不需要 `SameSite=None`。详见 [development-startup-cn.md](development-startup-cn.md)。
